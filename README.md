# 拆一拆

一个帮助你把“知道该做什么”变成“现在可以开始”的 Claude Code Skill。

它不会一次生成一整套宏大计划，而是每轮只给一个下一步，并询问：

> 这一步，你做得到还是做不到？

- 做得到：先执行，再根据结果继续推进。
- 做不到：说出卡点，Skill 会识别阻力并换一种拆法。
- 路径跑通后：选择形成习惯、归入阶段目标，或继续推进一次性事项。

## 安装

需要已安装 [Claude Code](https://docs.anthropic.com/en/docs/claude-code)。

```bash
git clone https://github.com/E-ZongBaobao/chai-yi-chai.git ~/.claude/skills/chai-yi-chai
```

重新启动 Claude Code 后即可使用。

## 使用

直接描述一件知道应该做、却难以开始或推进的事情，例如：

```text
帮我拆一拆：我想做表达训练，但一直没有开始。
```

也可以在执行中直接反馈：

```text
做不到，我不知道选什么话题。
```

Skill 会围绕当前卡点继续调整，而不是机械地把时间或数量缩小。

## 工作方式

1. 明确当前事项和完成方向；
2. 给出一个最小可执行动作；
3. 询问“做得到 / 做不到”；
4. 根据真实卡点取消选择、提供模板、补充资源、降低标准或切换路径；
5. 要求先执行，再根据结果继续；
6. 将跑通的行动变成习惯、阶段目标或下一项任务。

## 适合这些情况

- 知道道理，但真正执行时会退缩；
- 目标太大，不知道从哪里开始；
- 计划已经写好，却迟迟没有行动；
- 方法听懂了，在现场却用不出来；
- 想培养习惯，但第一步一直没有发生。
