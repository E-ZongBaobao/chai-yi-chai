# 拆一拆

一个帮助你把“知道该做什么”变成“现在可以开始”的 Agent Skill。

它不会一次生成一整套宏大计划，而是每轮只给一个下一步，并询问：

> 这一步，你做得到还是做不到？

- 做得到：先执行，再根据结果继续推进。
- 做不到：说出卡点，Skill 会识别阻力并换一种拆法。
- 路径跑通后：选择形成习惯、归入阶段目标，或继续推进一次性事项。

## 安装

下载本仓库中的 `SKILL.md`，按照所使用 Agent 的 Skill 安装方式导入。不同 Agent 的安装目录和方式可能不同，请以对应产品的说明为准。

如果使用 Claude Code，也可以执行：

```bash
git clone https://github.com/E-ZongBaobao/chai-yi-chai.git ~/.claude/skills/chai-yi-chai
```

## 使用

安装后，不需要记住特殊口令，直接输入一件想做但一直没开始的事情。

例如：

```text
我想开始健身，但一直没有行动。
```

```text
我想准备年度汇报，但不知道从哪里开始。
```

```text
我想做表达训练，但总是拖着不练。
```

```text
我想整理房间，可是一想到东西很多就不想动。
```

Agent 给出下一步后，按照真实感受回答“做得到”或“做不到”。如果做不到，继续说出具体卡点，例如：

```text
做不到，我不知道选什么话题。
```

Skill 会围绕当前卡点继续调整，而不是机械地把时间或数量缩小。

## 工作方式

1. 明确当前事项和完成方向；
2. 给出一个最小可执行动作；
3. 询问“做得到 / 做不到”；
4. 根据真实卡点取消选择、提供模板、补充资源、降低标准或切换路径；
5. 要求先执行，再根据结果继续；
6. 将跑通的行动变成习惯、阶段目标或下一项任务。

## 适合这些情况

- 知道道理，但真正执行时会退缩；
- 目标太大，不知道从哪里开始；
- 计划已经写好，却迟迟没有行动；
- 方法听懂了，在现场却用不出来；
- 想培养习惯，但第一步一直没有发生。
